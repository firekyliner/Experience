# 一、Machine Learning 基础

## 1. Explain the principle of gradient descent algorithm

### 原理

梯度下降是一种用于最小化损失函数的优化算法。通过计算损失函数关于模型参数的梯度，并沿梯度反方向更新参数。

公式：

$$\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)$$

其中：
- θ：模型参数
- η：学习率
- ∇J：损失函数梯度

### 核心

梯度方向代表函数增长最快方向，因此负梯度方向能够使损失下降。

## 2. High entropy means partitions are more uncertain or less uncertain?

答案：More uncertain。

熵用于衡量不确定性：

- 高熵：类别分布均匀，不确定性高；
- 低熵：类别集中，不确定性低。

## 3. Difference between supervised and unsupervised learning

监督学习使用带标签数据学习输入到输出的映射。

无监督学习使用无标签数据，发现数据内部结构。

区别：

- Supervised: labeled data
- Unsupervised: unlabeled data

---

## 4. Difference between GD and SGD

GD：每次使用全部训练数据计算梯度。

SGD：每次随机选择一个样本更新参数。

区别：

|方法|特点|
|-|-|
|GD|稳定但计算量大|
|SGD|速度快但梯度存在波动|

## 6. Overfitting and Underfitting

### Overfitting

模型过度学习训练数据中的噪声。

表现：训练集好，测试集差。

解决：
- 增加数据；
- 正则化；
- 剪枝；
- 降低模型复杂度。

### Underfitting

模型过于简单，没有学习有效规律。

解决：
- 增加模型复杂度；
- 增加有效特征；
- 减少正则化。

决策树容易过拟合原因：树深度无限增加，会学习噪声和异常样本。

# 二、Deep Learning 基础

## 14. L1 and L2 regularization

L1：

$$L=L_0+\lambda\sum|w|$$

特点：产生稀疏权重，可用于特征选择。

L2：

$$L=L_0+\lambda\sum w^2$$

特点：限制权重大小，提高稳定性。

---

## 15. Type I and Type II errors

Type I Error：

拒绝真实的原假设。

False Positive（假阳性）。

Type II Error：

没有拒绝错误的原假设。

False Negative（假阴性）。

## 21. Exploding gradient problem

## 22. Depthwise Separable Convolution

由两部分组成：

1. Depthwise Convolution：逐通道卷积；
2. Pointwise Convolution：1×1卷积融合通道。

优势：

- 减少参数量；
- 降低计算量；
- 适合移动端和嵌入式部署。

代表网络：MobileNet。

---

## 23. Pooling layer

作用：

- 降低特征图尺寸；
- 减少计算量；
- 提升一定平移鲁棒性。

常见方式：

### Max Pooling

取窗口最大值。

### Average Pooling

取窗口平均值。

### Global Average Pooling

整张特征图求平均，常用于分类网络末端。

# 三、计算机基础

## 堆和栈哪个效率高？

通常栈效率更高。

原因：

栈：
- 连续内存；
- 自动管理；
- 分配释放简单。

堆：
- 动态申请；
- 需要内存管理；
- 可能产生碎片。

# 四、数据不平衡问题

## 不平衡样本训练影响

模型容易偏向多数类别。

表现：

- Accuracy较高；
- 少数类Recall低。

解决：

### 数据层面

- Oversampling；
- Undersampling；
- 数据增强。

### Loss层面

- Class Weight；
- Weighted Cross Entropy；
- Focal Loss。

### 评价指标

不要只看Accuracy，应关注：

- Precision；
- Recall；
- F1-score；
- Confusion Matrix。
