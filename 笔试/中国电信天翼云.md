### 第1题 HTTP 资源不存在状态码

**题目：**
表示“请求的资源不存在”的 HTTP 状态码是什么？

**答案：404 Not Found**

**解析：**
HTTP 404 表示服务器能够正常接收并处理请求，但找不到客户端请求的资源，例如网页、接口路径或指定 ID 对应的数据不存在。

### 第2题 Linux 文件权限

**题目：**
某文件权限为：

```text
-rwxr-x---
```

如果一个用户属于该文件的所属组，但不是文件拥有者，那么该用户具有什么访问能力？

**答案：可读、可执行、不可写。**

**解析：**
权限可拆分为：

```text
-   rwx   r-x   ---
    所有者 所属组 其他用户
```

该用户属于文件所属组，因此使用中间的 `r-x` 权限：
- `r`：可读；
- `-`：不可写；
- `x`：可执行。

### 第3题 UDP 可靠传输

**题目：**
UDP 能否在传输层自动恢复丢失报文并按序交付？

**答案：不能。**

**解析：**
UDP 是无连接、不可靠的传输层协议，本身不提供：
- 丢包自动重传；
- 按序交付；
- 到达保证；
- 去重保证。

如果应用需要可靠传输，需要在应用层自行实现重传、排序、确认等机制，或者直接使用 TCP。

### 第4题 互斥锁死锁

**题目：**
T1 持有互斥锁 A 并等待锁 B，T2 持有锁 B 并等待锁 A，会发生什么？

**答案：死锁（Deadlock）。**

**解析：**
T1 等待 T2 释放 B，T2 同时等待 T1 释放 A，形成循环等待。如果没有超时、抢占或死锁检测/恢复机制，两个线程会一直阻塞。

### 第5题 Linux 正常终止进程

**题目：**
服务进程 PID 为 2468，如果希望让进程自行执行退出清理逻辑后再结束，应使用什么命令？

**答案：**

```bash
kill -TERM 2468
```

也可以写：

```bash
kill 2468
```

**解析：**
`kill` 默认发送 SIGTERM（信号 15），进程可以捕获该信号并执行资源释放、保存状态等清理逻辑后退出。

相比之下：

```bash
kill -9 2468
```

发送 SIGKILL，会直接强制终止进程，不给进程执行清理逻辑的机会。

### 第6题 线程与进程的关系

**题目：**
线程和进程之间是什么关系？

**答案：**
**进程是资源分配的基本单位，线程是 CPU 调度和执行的基本单位。**

**解析：**
一个进程可以包含一个或多个线程。同一进程中的线程共享大部分进程资源，例如：
- 代码段；
- 数据段；
- 堆；
- 打开的文件等。

但每个线程拥有自己独立的：
- 栈；
- 程序计数器；
- 寄存器上下文等。

因此可以简单记忆为：**进程拥有资源，线程在进程内部执行并共享资源。**

### 第7题 线程共享与进程通信

**题目：**
判断下面两个说法是否正确：

1. 同一进程内的线程可以直接访问共享地址空间中的任务队列，但队列操作仍需考虑并发安全。
2. 改为多进程后，各个进程默认共享同一份用户全局变量，因此不需要进程间通信。

**答案：**
1. **正确**
2. **错误**

**解析：**
同一进程内的多个线程共享地址空间，因此可以直接访问同一个全局变量、堆对象或任务队列，但同时读写时可能产生竞态条件，需要互斥锁、信号量、条件变量或线程安全队列等同步机制。

不同进程默认拥有各自独立的虚拟地址空间，普通全局变量并不共享。即使通过 `fork()` 创建子进程，通常也是写时复制（Copy-on-Write），一个进程修改变量不会直接影响另一个进程。

多进程间需要共享数据时，通常需要 IPC，例如：
- 共享内存；
- 管道；
- 消息队列；
- Socket 等。

### 第8题 HTTP 请求方法与响应状态码

**题目：**
GET、200 OK、201 Created 分别是什么意思？

**答案：**
- `GET`：HTTP 请求方法，用于获取资源；
- `200 OK`：请求成功；
- `201 Created`：请求成功，并成功创建了新资源。

**解析：**
需要区分“请求方法”和“响应状态码”。

常见 HTTP 请求方法：
- `GET`：获取资源；
- `POST`：提交数据或创建资源；
- `PUT`：通常用于整体更新资源；
- `PATCH`：通常用于部分更新资源；
- `DELETE`：删除资源。

常见 HTTP 状态码：
- `200 OK`：请求成功；
- `201 Created`：成功创建资源；
- `204 No Content`：请求成功，但没有响应正文；
- `400 Bad Request`：请求格式或参数错误；
- `401 Unauthorized`：未认证或认证失败；
- `403 Forbidden`：无访问权限；
- `404 Not Found`：资源不存在；
- `500 Internal Server Error`：服务器内部错误。

可以记忆为：**GET/POST/PUT/DELETE 表示“客户端要做什么”，200/201/404/500 表示“服务器处理结果如何”。**

### 第9题 排序算法复杂度

**题目：**
快速排序的平均时间复杂度和最坏时间复杂度分别是多少？归并排序的额外空间复杂度是多少？

**答案：**
- 快速排序平均时间复杂度：**O(n log n)**
- 快速排序最坏时间复杂度：**O(n²)**
- 归并排序额外空间复杂度：**O(n)**

**解析：**
快速排序在划分较均匀时递归深度约为 `log n`，每层处理 O(n)，因此平均 O(n log n)。如果每次基准划分都极不均衡，例如总是得到规模为 0 和 n−1 的两个部分，则退化为 O(n²)。

归并排序在合并两个有序区间时通常需要额外的临时数组，因此额外空间为 O(n)。

## 二、编程题

### 编程题 1：登舰许可管理

#### 题目

小月负责星港登舰许可管理。每张许可由唯一的许可编号 `id` 标识，并记录剩余可通过闸门的次数。初始时没有有效许可，按照顺序处理以下三类操作：

1. `ISSUE id k`  
   仅当编号 `id` 当前没有有效许可时，签发一张剩余次数为 `k` 的许可。

2. `PASS id`  
   仅当编号 `id` 当前有有效许可时，使用一次许可，剩余次数减 1；若减少到 0，该许可立即失效。

3. `CANCEL id`  
   仅当编号 `id` 当前有有效许可时，提前取消该许可。

被拒绝的操作不会改变任何状态。

最终输出：
- 成功通过闸门的次数；
- 被拒绝操作数；
- 最后有效许可数；
- 最后所有有效许可剩余次数之和。

输出一行四个整数。

#### 输入描述

第一行输入整数 `q`，表示操作数。

接下来 `q` 行，每行首先输入操作类型，随后输入对应参数：

```text
ISSUE id k
PASS id
CANCEL id
```

#### 思路

使用 `unordered_map<id, 剩余次数>` 维护当前所有有效许可。

- ISSUE：若 `id` 已存在则拒绝，否则插入；
- PASS：若不存在则拒绝，否则剩余次数减 1，并统计一次成功通行；若减为 0 则删除；
- CANCEL：若不存在则拒绝，否则删除。

最后遍历哈希表求剩余次数总和。

平均时间复杂度为 **O(q)**。

#### C++（ACM 模式 / Clang++11）

```cpp
#include <iostream>
#include <string>
#include <unordered_map>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;

    unordered_map<long long, long long> permit;

    long long passCnt = 0;
    long long rejectCnt = 0;

    for (int i = 0; i < q; ++i) {
        string op;
        cin >> op;

        if (op == "ISSUE") {
            long long id, k;
            cin >> id >> k;

            if (permit.count(id)) {
                ++rejectCnt;
            } else {
                permit[id] = k;
            }
        }
        else if (op == "PASS") {
            long long id;
            cin >> id;

            auto it = permit.find(id);

            if (it == permit.end()) {
                ++rejectCnt;
            } else {
                ++passCnt;
                --it->second;

                if (it->second == 0) {
                    permit.erase(it);
                }
            }
        }
        else if (op == "CANCEL") {
            long long id;
            cin >> id;

            auto it = permit.find(id);

            if (it == permit.end()) {
                ++rejectCnt;
            } else {
                permit.erase(it);
            }
        }
    }

    long long remainSum = 0;
    for (const auto &x : permit) {
        remainSum += x.second;
    }

    cout << passCnt << ' '
         << rejectCnt << ' '
         << permit.size() << ' '
         << remainSum << '\n';

    return 0;
}
```

### 编程题 2：最长相位平衡子数组

#### 题目

给定一个长度为 `n` 的整数序列和一个整数 `p (2 <= p <= 20)`。

对于任意子数组 `[l,r]`，按照相对于起点 `l` 的位置，将元素划分为 `p` 个相位：

```text
第 j 相位 = { i ∈ [l,r] | (i-l) mod p = j }
j = 0,1,...,p-1
```

每个相位的元素和称为该相位的“相位和”，若该相位为空则相位和为 0。

如果 `p` 个相位的相位和两两相等，则称子数组 `[l,r]` 为**相位平衡**。

求最长相位平衡子数组的长度，不存在则输出 0。

#### 输入描述

第一行输入整数 `T`，表示测试数据组数。

每组数据：

```text
n p
a1 a2 ... an
```

保证所有测试数据的 `n` 之和不超过 200000。

#### 核心思路

虽然题目相位使用：

```text
(i-l) mod p
```

定义，但当子数组起点改变时，只相当于把全局下标 `i mod p` 的 `p` 个余数类循环重新编号。

因此，“所有相位和相等”等价于：

> 子数组中，下标模 `p` 属于各个余数类的元素和全部相等。

设当前前缀中各余数类的和为：

```text
sum[0], sum[1], ..., sum[p-1]
```

定义状态：

```text
(sum[1]-sum[0],
 sum[2]-sum[0],
 ...
 sum[p-1]-sum[0])
```

如果两个前缀位置的状态完全相同，则它们之间的子数组中，各余数类的元素和完全相等，因此该区间就是相位平衡子数组。

为了让代码更容易理解，可以直接使用：

```cpp
map<vector<long long>, int>
```

记录每种状态第一次出现的位置。

#### C++（ACM 模式 / 简洁版）

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <algorithm>

using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n, p;
        cin >> n >> p;

        vector<ll> sum(p, 0);
        vector<ll> state(p - 1, 0);

        // 状态 -> 第一次出现的位置
        map<vector<ll>, int> first;
        first[state] = 0;

        int ans = 0;

        for (int i = 1; i <= n; ++i) {
            ll x;
            cin >> x;

            sum[i % p] += x;

            for (int j = 1; j < p; ++j) {
                state[j - 1] = sum[j] - sum[0];
            }

            auto it = first.find(state);

            if (it != first.end()) {
                ans = max(ans, i - it->second);
            } else {
                // 只保留第一次出现的位置，才能得到最长区间
                first[state] = i;
            }
        }

        cout << ans << '\n';
    }

    return 0;
}
```

**复杂度：**
- 状态维度最多为 19；
- 使用 `map` 时总体约为 **O(n · p · log n)**；
- 额外空间最坏约为 **O(n · p)**。

如果使用自定义哈希的 `unordered_map`，平均复杂度可进一步接近 O(n·p)，但代码更复杂。

### 编程题 3：相邻和均为合数的排列

#### 题目

给定一个正整数 `n`，构造一个长度为 `n` 的排列：

```text
p1, p2, ..., pn
```

要求：

1. `{p1,p2,...,pn}` 是 `{1,2,...,n}` 的一个排列；
2. 对所有 `1 <= i < n`，`pi + p(i+1)` 都是合数。

若不存在满足要求的排列，输出 `-1`；否则输出任意一种合法排列。

每个测试文件包含多组测试数据，且所有测试数据的 `n` 之和不超过 400000。

#### 核心思路

两个不同奇数相加一定得到大于 2 的偶数，因此一定是合数；两个偶数相加同样一定得到大于 2 的偶数，也是合数。

因此可以把：
- 所有奇数放在一起；
- 所有偶数放在一起。

唯一需要处理的是“奇数段”和“偶数段”的连接位置。

当 `n >= 5` 时，数字 5 和 4 一定存在：

```text
5 + 4 = 9
```

9 是合数。

因此可以构造：

```text
其他奇数 -> 5 -> 4 -> 其他偶数
```

特殊情况：
- `n = 1`：合法，输出 1；
- `n = 2,3,4`：无解；
- `n >= 5`：上述构造一定可行。

例如 `n = 8`：

```text
1 3 7 5 4 2 6 8
```

相邻和依次为：

```text
4, 10, 12, 9, 6, 8, 14
```

全部是合数。

#### C++（ACM 模式）

```cpp
#include <iostream>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;

        if (n == 1) {
            cout << 1 << '\n';
            continue;
        }

        if (n < 5) {
            cout << -1 << '\n';
            continue;
        }

        bool first = true;

        // 除 5 之外的所有奇数
        for (int i = 1; i <= n; i += 2) {
            if (i == 5) continue;

            if (!first) cout << ' ';
            cout << i;
            first = false;
        }

        // 奇偶连接：5 + 4 = 9
        if (!first) cout << ' ';
        cout << 5 << ' ' << 4;

        // 除 4 之外的所有偶数
        for (int i = 2; i <= n; i += 2) {
            if (i == 4) continue;
            cout << ' ' << i;
        }

        cout << '\n';
    }

    return 0;
}
```

**复杂度：**
每个数字只输出一次，因此时间复杂度为 **O(n)**，除输出本身外只需要 O(1) 额外空间。
