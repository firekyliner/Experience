## 一、ACM 模式说明

平台示例为多组输入，每行两个整数，输出两数之和，直到 EOF：

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b;
    while (cin >> a >> b) {
        cout << a + b << '\n';
    }

    return 0;
}
```

关键点是：

```cpp
while (cin >> a >> b)
```

表示持续读取直到输入结束。

## 二、编程题

### 编程题 1：自动驾驶车辆充电最短时间

#### 题目

一辆自动驾驶车辆需要在 `n` 个城市之间配送货物。

城市之间有 `m` 条双向道路，第 `i` 条道路连接城市 `u_i` 和 `v_i`，通行时间为 `w_i`，消耗能量 `e_i`。

车辆初始位于城市 `1`，初始能量为 `0`，目标是到达城市 `n`，车辆能量上限为 `E`。

车辆可以在任意城市 `i` 充电，每次充电 `1` 单位能量需要时间 `c_i`，不同城市充电速度不同。

通过一条道路需要消耗对应的能量 `e_i`，如果当前能量不足则不能通过。

求从城市 `1` 到城市 `n` 的最短总时间；如果无法到达，输出 `-1`。

#### 输入描述

第一行输入：

```text
n m E
```

第二行输入 `n` 个整数：

```text
c1 c2 ... cn
```

接下来 `m` 行，每行：

```text
u v w e
```

表示一条双向道路的两个端点、通行时间和能量消耗。

题面子任务中可见的范围：

- 20%：`n <= 10, E <= 5, m <= 20`
- 50%：`n <= 100, E <= 50, m <= 1000`
- 100%：`n <= 1000, E <= 100, m <= 10000`

#### 输出描述

输出从城市 `1` 到城市 `n` 的最短时间；无法到达时输出 `-1`。

#### 思路

普通最短路只把“城市”作为状态是不够的，因为：

> 到达同一个城市时，剩余电量不同，后续能够选择的道路和充电策略也不同。

因此将状态扩展为：

```text
(当前城市 u, 当前剩余电量 p)
```

其中：

```text
0 <= p <= E
```

定义：

```text
dist[u][p]
```

表示“到达城市 `u` 且剩余 `p` 单位能量时的最短时间”。

每个状态有两种转移：

1. **充 1 单位电**

```text
(u, p) -> (u, p + 1)
```

耗时 `c[u]`。

2. **通过道路**

对于道路 `u -> v`，若当前电量 `p >= e`：

```text
(u, p) -> (v, p - e)
```

耗时 `w`。

所有边权均非负，因此可以在扩展状态图上使用 Dijkstra。

#### C++（ACM 模式）

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

struct Edge {
    int to;
    ll time;
    int energy;
};

struct State {
    ll dist;
    int city;
    int energy;

    State(ll d, int c, int e)
        : dist(d), city(c), energy(e) {}

    bool operator>(const State& other) const {
        return dist > other.dist;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, E;
    cin >> n >> m >> E;

    vector<ll> c(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> c[i];
    }

    vector<vector<Edge>> graph(n + 1);

    for (int i = 0; i < m; ++i) {
        int u, v, e;
        ll w;

        cin >> u >> v >> w >> e;

        graph[u].push_back({v, w, e});
        graph[v].push_back({u, w, e});
    }

    const ll INF = LLONG_MAX / 4;

    vector<vector<ll>> dist(
        n + 1,
        vector<ll>(E + 1, INF)
    );

    priority_queue<
        State,
        vector<State>,
        greater<State>
    > pq;

    dist[1][0] = 0;
    pq.push(State(0, 1, 0));

    while (!pq.empty()) {
        State cur = pq.top();
        pq.pop();

        ll d = cur.dist;
        int u = cur.city;
        int power = cur.energy;

        if (d != dist[u][power]) {
            continue;
        }

        if (u == n) {
            cout << d << '\n';
            return 0;
        }

        // 1. 充 1 单位电
        if (power < E) {
            ll nd = d + c[u];

            if (nd < dist[u][power + 1]) {
                dist[u][power + 1] = nd;
                pq.push(State(nd, u, power + 1));
            }
        }

        // 2. 通过道路
        for (const auto& edge : graph[u]) {
            if (power >= edge.energy) {
                int v = edge.to;
                int newPower = power - edge.energy;
                ll nd = d + edge.time;

                if (nd < dist[v][newPower]) {
                    dist[v][newPower] = nd;
                    pq.push(State(nd, v, newPower));
                }
            }
        }
    }

    cout << -1 << '\n';

    return 0;
}
```

#### 复杂度

扩展状态数约为：

```text
n * (E + 1)
```

道路转移最多在每个电量状态下被处理一次量级，因此：

- 时间复杂度：约 `O((nE + mE) log(nE))`
- 空间复杂度：`O(nE + m)`

#### 本次调试中的易错点

1. **总时间相关变量统一使用 `long long`。**

至少包括：

```text
Edge::time
c[i]
dist[u][power]
w
nd
```

避免多次充电和多条道路累加后溢出 `int`。

2. 道路输入顺序是：

```cpp
cin >> u >> v >> w >> e;
```

其中 `w` 是时间，`e` 是能量消耗，不要写反。

3. 初始状态是：

```cpp
dist[1][0] = 0;
```

车辆不是满电出发。

4. 若平台对：

```cpp
pq.push({nd, v, newPower});
```

出现初始化兼容问题，可给 `State` 增加构造函数，并显式写成：

```cpp
pq.push(State(nd, v, newPower));
```

5. `INF` 不建议写成：

```cpp
const ll INF = 4e18;
```

因为 `4e18` 是浮点字面量。使用：

```cpp
const ll INF = LLONG_MAX / 4;
```

更稳妥。

### 编程题 2：淘汰赛中两辆关注车辆是否相遇

#### 题目

一项自动驾驶赛车采用淘汰赛制。

每辆车都有一个最终用于比较实力/排名的分数，分数越高排名越靠前。每轮比赛中，当前序列里的车辆两两进行比赛，分数更高的车辆晋级下一轮，直到产生最终胜者。

给定某一年比赛：

- 参赛车辆数量 `m`；
- 两个关注排名 `j` 和 `k`；
- 第一轮的车辆排列顺序；
- 编号为 `1...m` 的每辆车对应分数。

需要先根据分数确定“排名第 `j` 的车辆”和“排名第 `k` 的车辆”，再判断这两辆车在整届淘汰赛中是否曾经直接进行过比赛。

若进行过，称当年比赛“有趣”。

给定之前 `n` 年的数据，逐年输出判断结果。

#### 输入描述

第一行输入年份数 `n`，题面可见：

```text
0 < n <= 20
```

接下来每一年使用 3 行数据：

第一行：

```text
m j k
```

第二行包含 `m` 个整数，表示第一轮车辆顺序。

第三行包含 `m` 个分数，第 `i` 个数表示编号为 `i` 的车辆分数。

分数范围可达到约 `1e18`，应使用 `long long`。

#### 输出描述

对每一年输出一行：

- 若两辆关注车辆直接比赛过，输出：

```text
YQST
```

- 否则输出：

```text
...
```

#### 样例输入

```text
2
4 1 4
1 3 2 4
1 3 2 4
4 1 2
1 3 2 4
4 3 1 2
```

#### 样例输出

```text
...
YQST
```

#### 思路

分两步处理。

第一步，根据所有车辆分数从高到低排序：

```text
rank[j - 1] -> 排名第 j 的车辆编号
rank[k - 1] -> 排名第 k 的车辆编号
```

第二步，按照第一轮给定的顺序模拟淘汰赛：

- 当前序列中每相邻两辆车比赛；
- 检查这两辆车是否正好是关注车辆；
- 分数更高者进入下一轮；
- 下一轮继续两两比赛。

每轮车辆数减半，因此实际比赛总数为 `m - 1`。

#### C++（ACM 模式）

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    while (n--) {
        int m, j, k;
        cin >> m >> j >> k;

        vector<int> order(m);
        for (int i = 0; i < m; ++i) {
            cin >> order[i];
        }

        vector<ll> score(m + 1);
        for (int i = 1; i <= m; ++i) {
            cin >> score[i];
        }

        vector<pair<ll, int>> rank;

        for (int i = 1; i <= m; ++i) {
            rank.push_back({score[i], i});
        }

        sort(rank.begin(), rank.end(),
             [](const pair<ll, int>& a,
                const pair<ll, int>& b) {
                 return a.first > b.first;
             });

        int carJ = rank[j - 1].second;
        int carK = rank[k - 1].second;

        bool interesting = false;

        vector<int> cur = order;

        while (cur.size() > 1) {
            vector<int> nextRound;

            for (int i = 0; i < (int)cur.size(); i += 2) {
                int a = cur[i];
                int b = cur[i + 1];

                if ((a == carJ && b == carK) ||
                    (a == carK && b == carJ)) {
                    interesting = true;
                }

                if (score[a] > score[b]) {
                    nextRound.push_back(a);
                } else {
                    nextRound.push_back(b);
                }
            }

            cur = nextRound;
        }

        if (interesting) {
            cout << "YQST\n";
        } else {
            cout << "...\n";
        }
    }

    return 0;
}
```

#### 复杂度

- 按分数排序：`O(m log m)`
- 淘汰赛模拟：`O(m)`
- 总时间复杂度：`O(m log m)`
- 额外空间复杂度：`O(m)`

#### 本次调试中的实际 Bug

现场代码中读取分数时误写成了：

```cpp
vector<ll> score(m + 1);

for (int i = 1; i <= m; i++) {
    cin >> order[i];   // 错误
}
```

正确写法是：

```cpp
vector<ll> score(m + 1);

for (int i = 1; i <= m; i++) {
    cin >> score[i];   // 正确
}
```

这个错误会同时导致：

1. `score` 没有真正读入，默认全为 0，导致排名完全错误；
2. `order` 长度为 `m`，合法下标为 `0...m-1`，但循环会访问 `order[m]`，发生越界。

正确的两段输入应明确区分：

```cpp
vector<int> order(m);
for (int i = 0; i < m; i++) {
    cin >> order[i];
}

vector<ll> score(m + 1);
for (int i = 1; i <= m; i++) {
    cin >> score[i];
}
```

### 编程题 3：总部到机场路线的最小瓶颈长度

#### 题目

文经理准备在 G 市开展点对点到机场的自动驾驶接送服务，希望连通文远智行总部（编号 `1`）和机场（编号 `n`）。

现有 `n` 个停靠点，路测确认其中有 `m` 对停靠点之间可以建立点对点自动驾驶路线。

每条可用路线连接 `u_i` 和 `v_i`，长度为 `l_i`。

实习生小远负责规划一条从总部到机场的路线。路线确定后，文经理最多亲自处理其中 `k` 条较长的点对点路线，剩余路线交给小远完成。

小远希望：

> 自己最终负责的所有路线中，最长的那一条尽可能短。

求这个最小可能值。如果总部无法到达机场，输出 `-1`。

#### 输入描述

第一行输入：

```text
n m k
```

接下来 `m` 行：

```text
u v l
```

表示停靠点 `u` 和 `v` 之间存在一条长度为 `l` 的双向路线。

题面给出的数据范围：

50% 数据：

```text
n <= 30
m <= 50
k <= 10
l_i <= 1000000
```

100% 数据：

```text
n <= 1000
m <= 10000
k <= m
l_i <= 1000000
```

#### 输出描述

输出一个整数，表示小远负责的路线中最长路线长度的最小可能值。

若无法从 `1` 到达 `n`，输出：

```text
-1
```

#### 思路

这道题不是普通的“路径总长度最短”。

目标是：

> 选择一条 `1 -> n` 的路径，并允许其中最多 `k` 条较长边交给文经理，使剩余边中的最大长度最小。

可以使用 **二分答案 + 0-1 BFS**。

假设当前二分一个答案 `limit`，表示要求小远负责的路线长度都不能超过 `limit`。

对于每条边：

- 如果 `w <= limit`，小远可以负责，记代价为 `0`；
- 如果 `w > limit`，必须交给文经理，记代价为 `1`。

于是问题变成：

> 从 `1` 到 `n`，最少需要经过多少条“长度大于 limit”的边？

因为边权只有 0 和 1，可以用 0-1 BFS。

如果最少数量 `<= k`，说明当前 `limit` 可行；否则不可行。

可行性随 `limit` 增大单调，因此可以二分最小可行值。

#### C++（ACM 模式）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge {
    int to;
    int w;
};

int n, m, k;
vector<vector<Edge>> graph;

bool check(int limit) {
    const int INF = 1e9;

    vector<int> dist(n + 1, INF);
    deque<int> q;

    dist[1] = 0;
    q.push_front(1);

    while (!q.empty()) {
        int u = q.front();
        q.pop_front();

        for (const auto& edge : graph[u]) {
            int v = edge.to;
            int cost = (edge.w > limit ? 1 : 0);

            if (dist[v] > dist[u] + cost) {
                dist[v] = dist[u] + cost;

                if (cost == 0) {
                    q.push_front(v);
                } else {
                    q.push_back(v);
                }
            }
        }
    }

    return dist[n] <= k;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m >> k;

    graph.resize(n + 1);

    int maxW = 0;

    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;

        graph[u].push_back({v, w});
        graph[v].push_back({u, w});

        maxW = max(maxW, w);
    }

    // limit = maxW 时所有现有边代价均为 0。
    // 此时仍到不了 n，说明原图本身不连通。
    if (!check(maxW)) {
        cout << -1 << '\n';
        return 0;
    }

    int left = 0;
    int right = maxW;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (check(mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    cout << left << '\n';

    return 0;
}
```

#### 复杂度

一次 `check(limit)` 使用 0-1 BFS：

- 时间复杂度：`O(n + m)`
- 空间复杂度：`O(n + m)`

二分约进行 `O(log maxL)` 次，其中 `maxL <= 1e6`。

因此总时间复杂度：

```text
O((n + m) log maxL)
```

#### 易错点

1. **不是普通 Dijkstra 的路径长度求和问题。**

题目优化的是“最多去掉/转交 `k` 条边后，剩余边的最大值”。

2. 对固定 `limit`，边的代价应该定义为：

```cpp
int cost = (edge.w > limit ? 1 : 0);
```

这里统计的是“需要文经理处理的边数”。

3. 道路是双向的，需要同时加入：

```cpp
graph[u].push_back({v, w});
graph[v].push_back({u, w});
```

4. 二分下界可以从 `0` 开始。

如果存在一条路径，其边数不超过 `k`，则所有边都可以交给文经理，此时答案可以为 `0`。

## 三、笔试知识点总结

本次 3 道正式编程题覆盖的重点比较集中：

- **状态扩展最短路**：把“城市”扩展为“城市 + 剩余电量”，在状态图上跑 Dijkstra；
- **模拟 + 排序**：先根据分数找出目标车辆，再模拟淘汰赛晋级过程；
- **二分答案 + 0-1 BFS**：把“最小化剩余边最大值”转化为阈值判定问题；
- **ACM 输入输出**：EOF 多组输入、无提示语标准输入输出；
- **数据类型意识**：累计时间与最高可达 `1e18` 的分数使用 `long long`；
- **数组下标与读入对象**：尤其注意 `order` 使用 0 下标、`score` 按车辆编号使用 1 下标。

从现场调试过程看，算法本身之外最容易失分的是“读错变量、下标越界、数据类型不够、输入字段顺序写反”等实现细节。正式提交前应优先用样例检查输入读取，再检查边界值和类型。
