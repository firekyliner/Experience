### 编程题 1：求完成生产任务的最少时间

#### 题目

给定一个整数数组 `time`，其中 `time[i]` 表示第 `i` 台机器生产一件产品所需的时间。给定整数 `totalProduct` 表示需要生产的产品总数。所有机器可以同时、独立运行，求完成全部生产任务所需的最少时间。

约束：

- `0 < time[i] <= 100000`
- `0 < totalProduct <= 2^31 - 1`

#### 输入描述

- 第一行输入整数 `n`，表示机器数量。
- 第二行输入 `n) 个整数，表示数组 `time`。
- 第三行输入整数 `totalProduct`。

#### 输出描述

输出完成生产任务所需的最少时间。

#### 样例输入

```text
1
2
2
```

#### 样例输出

```text
4
```

#### 思路

使用**答案二分**。假设给定时间为 `T`，第 `i` 台机器可以生产 `T // time[i]` 件产品，因此总产量为：

```text
count(T) = sum(T // time[i])
```

当 `count(T) >= totalProduct` 时，说明时间 `T` 足够，可以尝试更短的时间；否则需要增加时间。总产量随时间单调不减，因此可二分查找第一个满足条件的时间。

- 搜索左边界：`0`。
- 搜索右边界：`min(time) * totalProduct`，即最快机器独立完成全部任务所需的时间。
- 使用 `while left < right` 的左边界模板：满足条件时令 `right = mid`，不满足时令 `left = mid + 1`。

#### Python3（平台函数模式）

```python
def func():
    n = int(input())
    times = list(map(int, input().split()))
    total_product = int(input())

    left = 0
    right = min(times) * total_product

    while left < right:
        mid = (left + right) // 2

        count = 0
        for t in times:
            count += mid // t
            if count >= total_product:
                break

        if count >= total_product:
            right = mid
        else:
            left = mid + 1

    print(left)


if __name__ == "__main__":
    func()
```

**复杂度：** 时间复杂度 `O(n log(min(time) * totalProduct))`；存储输入数组需要 `O(n)) 空间，二分过程额外空间为 `O(1)`。Python 整数不会溢出；若使用 C++，时间上界及产量计算应使用 `long long`。

### 编程题 2：最小的段长

#### 题目

给定一个包含 `N` 个正整数的数组，将其划分为若干个连续且互不重叠的子数组。如果每个子数组的元素和都相等，则称这种划分为合法划分。

每个子数组称为一段。一次划分的段长定义为所有子数组长度中的最大值。要求在所有合法划分中，求这个最大段长的最小值。

约束：

- 测试用例数量：`1 <= T <= 1000`
- 每组数组长度：`1 <= N <= 2000`
- 数组元素：`1 <= a[i] <= 10^6`

#### 输入描述

- 第一行输入测试用例数量 `T`。
- 每组测试用例第一行输入数组长度 `N`。
- 随后输入该数组的 `N` 个正整数。

#### 输出描述

每组测试用例输出一个整数，表示该数组所有合法等和连续划分中，最大段长的最小值。

#### 样例输入

```text
4
6
55 45 30 30 40 100
4
10 23 7 13
5
10 55 35 30 65
6
4 1 1 1 1 4
```

#### 样例输出

```text
3
4
2
3
```

#### 思路

关键是利用**正整数数组的前缀和严格递增**这一性质。

设数组总和为 `S`。若每段的元素和为 `target`，则必须满足：

```text
S % target == 0
```

设段数为 `k = S // target`。合法划分的所有切分位置，必须分别对应前缀和：

```text
target, 2 * target, ..., (k - 1) * target
```

先建立“前缀和 -> 对应下标”的哈希表。然后枚举数组前缀和作为候选 `target`：

1. 若 `S % target != 0`，跳过。
2. 计算段数 `k = S // target`；若 `k > N`，跳过，因为每段至少包含一个元素。
3. 检查 `target, 2 * target, ..., k * target` 是否都能在前缀和哈希表中找到。
4. 找到全部切分位置后，相邻切分位置的下标差就是每段长度，取其中最大值。
5. 对所有合法候选，取最大段长的最小值。

因为数组元素均为正数，前缀和严格递增，同一个前缀和值至多对应一个下标；因此上述切分位置检查充分且不会出现重复前缀和歧义。

#### Python3（ACM 模式）

```python
import sys


def solve(a):
    n = len(a)
    total = sum(a)

    # prefix_pos[p] 表示前缀和 p 对应的元素个数（切分下标）
    prefix_pos = {0: 0}
    prefix = 0

    for i, x in enumerate(a, 1):
        prefix += x
        prefix_pos[prefix] = i

    ans = n

    # 每个合法 target 必须是某个非空前缀和
    for target in prefix_pos:
        if target == 0 or total % target != 0:
            continue

        k = total // target
        if k > n:
            continue

        prev = 0
        max_len = 0
        valid = True

        # 检查每个累计段和对应的切分位置
        for j in range(1, k + 1):
            pos = prefix_pos.get(j * target)
            if pos is None:
                valid = False
                break

            max_len = max(max_len, pos - prev)
            prev = pos

        if valid:
            ans = min(ans, max_len)

    return ans


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    t = data[0]
    idx = 1
    results = []

    for _ in range(t):
        n = data[idx]
        idx += 1
        a = data[idx:idx + n]
        idx += n
        results.append(str(solve(a)))

    print("\\n".join(results))


if __name__ == "__main__":
    main()
```

**复杂度：** 前缀和及哈希表建立需要 `O(N)`。对每个候选前缀和，最多检查 `k <= N` 个切分位置，因此单组最坏时间复杂度为 `O(N^2)`，空间复杂度为 `O(N)`。该实现利用哈希表避免了每个候选都重新扫描原数组；但题目给出最多 1000 组测试，未提供所有测试的 `N` 总和约束，极端总数据量下仍需关注总运行时间。

#### 样例解释

- 第 1 组：数组总和为 300。取每段和为 100，可切成 `[55,45]`、`[30,30,40]`、`[100]`，段长分别为 2、3、1，最大段长为 3。
- 第 2 组：总和为 53，只能整体作为一段，段长为 4。
- 第 3 组：总和为 195，取每段和为 65，可切成 `[10,55]`、`[35,30]`、`[65]`，最大段长为 2。
- 第 4 组：取每段和为 6，可切成 `[4,1,1]`、`[1,1,4]`，最大段长为 3。

#### 易错点与复盘

- 不能只计算段数，还必须计算每段实际包含的元素个数，并取最大值。
- 划分必须连续且不重叠，不能通过任意组合元素凑出相同的和。
- 正整数条件很重要：它保证前缀和严格递增。
- 整个数组本身始终可以作为一段，因此合法划分一定存在，答案不会超过 `N`。
- 之前的直接枚举候选段和并对原数组反复扫描的写法，逻辑上可行但单组最坏为 `O(N^2)`；本次整理改为前缀和下标哈希表，减少重复扫描。

### 编程题 3：剪绳子得到 M 根等长绳子的最大长度

#### 题目

输入 `N` 根绳子的长度，它们均为正整数，记为 `L1, L2, ..., LN`。从这 `N` 根绳子中裁剪出 `M` 根等长绳子，求能够得到的最大整数长度。

约束：`N, M < 100000`，绳长均为正整数。

#### 输入描述

输入 `N + 1` 个正整数，以空格分隔：

- 第一个整数为 `M`，表示需要裁剪出的等长绳子数量。
- 后面的 `N` 个整数表示 `N` 根原始绳子的长度。

注意：输入中没有单独给出 `N`，需要通过读取全部整数并扣除第一个数来确定绳子数量。

#### 输出描述

输出一个整数，表示能够裁剪出的 `M` 根等长绳子的最大长度。

#### 样例输入

```text
3 1 201 401
```

#### 样例输出

```text
200
```

#### 思路

使用**答案二分**。假设每根目标绳子的长度为 `x`，长度为 `L[i]` 的原绳子可以裁剪出：

```text
L[i] // x
```

根目标绳子。总数量为：

```text
count(x) = sum(L[i] // x)
```

当 `count(x) >= M` 时，说明长度 `x` 可行，可以尝试更大的长度；否则需要缩短目标长度。可行性随目标长度增大而单调不增，因此二分寻找最大可行长度。

#### Python3（平台函数模式）

```python
def func():
    import sys
    data = list(map(int, sys.stdin.buffer.read().split()))

    m = data[0]
    ropes = data[1:]

    left = 1
    right = max(ropes)
    ans = 0

    while left <= right:
        mid = (left + right) // 2

        count = 0
        for length in ropes:
            count += length // mid
            if count >= m:
                break

        if count >= m:
            ans = mid
            left = mid + 1
        else:
            right = mid - 1

    print(ans)


if __name__ == "__main__":
    func()
```

**复杂度：** 时间复杂度 `O(N log Lmax)`，其中 `Lmax` 为最长原绳子的长度；空间复杂度 `O(N)`，用于存储输入绳长。

#### 样例解释

目标长度为 200 时：

- 长度 1 的绳子可以裁剪 0 根；
- 长度 201 的绳子可以裁剪 1 根；
- 长度 401 的绳子可以裁剪 2 根。

总计 3 根，满足要求。若目标长度为 201，则只能得到 2 根，因此最大可行长度为 200。

## 二、算法与笔试复盘

### 1. 本次涉及的核心算法

| 编程题 | 核心算法 | 关键性质 |
| --- | --- | --- |
| 求完成生产任务的最少时间 | 二分查找答案 | 总产量随时间单调不减，寻找第一个可行时间 |
| 最小的段长 | 前缀和 + 哈希表 + 枚举候选段和 | 等和连续划分的切分点必须对应前缀和的整数倍 |
| 剪绳子 | 二分查找答案 | 目标绳长越大，可裁剪数量越少，寻找最大可行长度 |

### 2. 二分查找边界复盘

第一题和第三题的二分模板不同，原因是优化目标不同。

**第一题：寻找最小可行时间**

```python
while left < right:
    mid = (left + right) // 2
    if check(mid):
        right = mid
    else:
        left = mid + 1
return left
```

满足条件时保留 `mid`，因为它可能是最小答案；区间收敛到 `left == right` 时结束。

**第三题：寻找最大可行绳长**

```python
while left <= right:
    mid = (left + right) // 2
    if check(mid):
        ans = mid
        left = mid + 1
    else:
        right = mid - 1
return ans
```

满足条件时记录答案并向更大的长度搜索；不满足时排除当前长度及更大的不可行区域。

注意：`left < right` 与 `left <= right` 并非简单地由“求最小值/最大值”决定。两种写法都可用于不同边界模板，必须确保区间定义、更新方式和最终返回值一致。
