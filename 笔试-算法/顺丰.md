# 一、客观题

## 1. 第 k 小元素查找

**题目关键词：** 1000000 个数据中查找第 k 小元素。

**答案：** 快速选择算法。

**解析：**

快速选择平均时间复杂度为 O(n)，只需要递归处理一侧分区；完全排序为 O(nlogn)，堆方法为 O(nlogk)，计数排序依赖数据范围。

---

## 2. 最长摆动子序列

**答案：** 贪心算法时间复杂度 O(n)。

**解析：**

维护当前上升和下降状态，只遍历一次序列即可得到最长摆动子序列。

---

## 3. TensorFlow2 model.fit 返回对象

**答案：** History 对象。

**解析：**

包含训练过程中的 loss、accuracy、val_loss 等指标记录，不包含模型权重。

---

## 4. HMM 前向算法与维特比算法

**答案：** 前向算法用于计算概率，维特比算法确定最优隐含状态序列。

**解析：**

Forward 计算观测序列概率；Viterbi 使用动态规划寻找最大概率状态路径。

---

## 5. Python 不可变参数类型

**答案：** number。

**解析：**

int、float 等数字类型不可变；list、dict、set 均属于可变类型。

---

## 6. Python 类方法调用与多态

**答案：** `Bird.fly(ostrich)` 调用父类方法，输出 `Bird.fly`。

**解析：**

显式指定类方法不会触发实例方法动态绑定；`ostrich.fly()` 才会调用子类重写方法。

**解析：**

每次将搜索区间缩小一半。

## 12. 结构化剪枝与非结构化剪枝

**答案：** 结构化剪枝按通道或注意力头整体裁剪，更容易被现有算子利用。

## 13. LLM 连续批处理吞吐计算

已知：

- 单卡吞吐 1600 token/s
- 单请求输出 400 token
- SLA ≥20 token/s

计算：

```
并发 = 1600 / 20 = 80
请求吞吐 = 1600 / 400 = 4 req/s
```

答案：约 80 并发，4 请求/s。

# 二、编程题

## 编程题 1：切纸片

### 题目

给定纸片长宽和目标数量，每次只能沿中线将偶数边长切成两半，判断是否可以得到至少 n 张小纸片。

### 思路

每次切割都会使数量乘 2。

统计长和宽中 2 的因子数量：

```
w = w / 2
h = h / 2
```

累计可获得纸片数量是否达到 n。

### Python3 ACM

```python
import sys

for line in sys.stdin:
    pass
```
