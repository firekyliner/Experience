## 一、单选题（已记录 12/25 道）

### 第1题 哈夫曼树的带权路径长度

**题目：** 给定 4 个叶子节点，权值分别为 2、3、5、7，构造哈夫曼树，其带权路径长度是多少？

**答案：** 32。

**解析：** 每次合并最小两个权值：2+3=5，再合并 5+5=10，最后 7+10=17。带权路径长度等于各次合并权值之和，即 5+10+17=32。

### 第2题 可能引起进程饥饿的调度算法

**题目：** 哪种进程调度算法可能引起进程饥饿？

**答案：** 优先级调度、短作业优先（SJF）都可能导致饥饿；若原题是单选，须依据原选项确定唯一答案。

**解析：** 持续到来的高优先级进程可能阻塞低优先级进程；不断到来的短作业也可能使长作业得不到执行。时间片轮转和先来先服务通常不会出现这种意义上的饥饿。

### 第3题 大小端与强制类型转换

**题目：**

~~~cpp
uint32_t x = 0x11223344;
uint16_t *p = (uint16_t *)&x;
printf("%04X %04X\n", p[0], p[1]);
~~~

**答案：** 常见小端平台的预期结果为 3344 1122；大端平台为 1122 3344。

**解析：** 小端内存从低地址到高地址依次为 44 33 22 11，连续两个 16 位读取分别得到 0x3344 和 0x1122。**标准层面注意：** 该写法还涉及严格别名规则，不能把字节序分析当作对所有 C 编译环境的绝对保证。

### 第4题 C 语言字符常量和字符串常量

**题目：** 在 C 语言中，给定 char mark = '#';，字符常量 '#' 与字符串常量 "#" 分别占多少字节？

**答案：** 若指 sizeof('#') 和 sizeof("#")，常见平台是 **4 字节、2 字节**；变量 mark 自身是 **1 字节**。

**解析：** C 语言中普通字符常量的类型是 int，因此 sizeof('#') = sizeof(int)，不保证所有平台必为 4；字符串 "#" 包含字符 '#' 和结尾 '\0'，所以数组大小为 2。原题若说的是 mark 而非字符常量，应答 1 和 2。

### 第5题 完全二叉树节点数量的优化计算

**题目：** 计算完全二叉树节点总数，要求时间复杂度低于 O(n)，能否先求树高，再对最后一层做二分查找？

**答案：** 可以；常见最优于线性遍历的方法是 **O(log² n)** 的完全二叉树计数。

**解析：** 先沿最左路径求高 h（以边数计），前 h 层节点数为 2^h-1。最后一层可能有 0 到 2^h 个节点，根据完全二叉树节点从左向右连续存在的性质，二分查找该层第一个不存在的下标。每次判断需要沿根到叶走 O(log n)，二分 O(log n) 次。也可用“判断哪侧是满二叉树”的递归法达到相同时间复杂度。

### 第6题 数组指针与 &a+1

**题目：**

~~~cpp
int a[5] = {1, 2, 3, 4, 5};
int *ptr = (int *)(&a + 1);
printf("%d, %d", *(a + 1), *(ptr - 1));
~~~

**答案：** 常见笔试预期输出 2, 5。

**解析：** a+1 指向第二个元素；&a 是指向整个数组的指针，&a+1 越过整个数组，转换为 int* 后向前退一项落到末元素。**注意：** 此类越界指针转换与回退不是推荐的严格可移植写法，实际代码宜直接使用 a[4] 或 a+4。

### 第7题 避免资源分配死锁的最大进程数

**题目：** 系统有 11 台打印机，每个进程最多需要 3 台，为保证不发生死锁，进程数不超过多少？

**答案：** 5 个。

**解析：** 在同类、可重复使用且正常释放的资源假设下，为保证至少一个进程最终可获得全部资源，需满足 R >= N(K-1)+1。代入 11 >= 2N+1，得 N<=5。若 6 个进程，可构造各占有部分资源、均等待剩余资源的死锁状态。

### 第8题 几乎有序数据的排序算法

**题目：** 对几乎有序的数据，应优先选择哪种排序方法？

**答案：** 直接插入排序。

**解析：** 数据接近有序时，每个元素需要移动的距离较短，插入排序接近 O(n)；最坏情况下为 O(n²)，额外空间 O(1)。

### 第9题 AVL 树旋转类型

**题目：** 在平衡二叉树插入节点时，最小不平衡子树根节点的平衡因子为 -2，其**左孩子**的平衡因子为 -1，应进行什么旋转？

**答案：** 按通常定义 BF=左高-右高，**仅凭题述条件无法唯一确定旋转类型**。

**解析：** 根节点 -2 表示右侧过高，此时应检查**右孩子**：右孩子为 -1 对应 RR 型，单次左旋；右孩子为 +1 对应 RL 型，先右旋后左旋。若题目把“左孩子”误写为“右孩子”，则预期是 RR 型。保留原题表述，不擅自改题。

### 第10题 std::function 与 Lambda

**题目：** 判断有关 std::function 的说法：①性能低于裸函数指针；②可以存储成员函数指针；③可以存储 Lambda 表达式。后续追问：裸函数指针能否直接存储有捕获 Lambda？

**答案：** ②③正确；①是**通常成立的性能经验**而非标准保证。普通函数指针不能直接接收有捕获 Lambda，通常可接收无捕获 Lambda。

**解析：** std::function 支持类型擦除及可调用对象封装，可存储签名匹配的 Lambda，也能包装非静态成员函数指针（调用时须提供对象）。封装带来可能的间接调用/分配开销，但具体速度依赖优化。C++11 的 std::function 要求被包装的目标可复制，不能包装所有仅可移动的闭包。原题选项与单选设问存在歧义，不据此虚构唯一选项字母。

### 第11题 C++ 左值、纯右值和将亡值

**题目：** 判断以下说法哪项错误：①将亡值是右值的一种，代表资源即将被移走；②纯右值没有地址，不能取址；③函数返回值（非引用）始终是左值；④左值有地址，可以取址。

**答案：** 按常见考试意图，**③错误**。

**解析：** 按值返回的函数调用表达式通常是纯右值，而非左值；将亡值属于右值但不意味着资源一定移动。④“左值均可以取址”也过于绝对，例如位域是左值却不能使用内置取地址运算符。题目有一定表述歧义，应结合备选答案理解。

### 第12题 01 背包是否必须回溯

**题目：** 求 01 背包的最优价值，是否必须使用回溯？

**答案：** 不需要；用动态规划即可求最优价值。

**解析：** 一维动态规划从大到小更新容量：dp[j]=max(dp[j],dp[j-w[i]]+v[i])，避免重复选择同一物品。时间 O(nW)、空间 O(W)；需要恢复具体选中物品时，才考虑根据 DP 结果反向追踪。这里 O(nW) 是伪多项式时间。

### 问答题 1：Kruskal 最小生成树代码阅读与白盒测试

**题目：** 阅读给定 C++ 代码（包含 Edge、Graph、find、Union、KruskalMST），评价代码好在哪里、不好在哪里；针对代码功能设计白盒测试用例并说明方法。原图给出了完整代码，以下保留其关键实现与问题，不逐字转录整页截图。

**参考答案：**

**功能与优点：** 代码通过按边权升序排序实现 Kruskal 算法，利用并查集查找环、路径压缩及按秩合并提升性能，成功处理连通无向加权图时可得到最小生成树，总时间复杂度约 O(E log E)。

**问题与修改：** ① Union 函数可增加 xroot == yroot 时直接返回的保护判断；虽然当前主调用已判断两个根不同，该保护仍有利于函数独立使用。② 图不连通时会提前耗尽边，结果不足 V-1 条，但代码仍按“最小生成树”输出，应在结束后检测 e == V-1，否则报告非连通。③ 应检查 V、E、边端点下标，以及 E 与 edges.size() 的一致性，防止越界。④ 用 long long 保存总权值，降低累加溢出风险。

**白盒测试：** 使用**分支覆盖 + 边界值测试**。针对 find，覆盖“根节点直接返回”和“递归路径压缩”；针对 Union，覆盖 rank 小于、大于、等于以及两根相同；针对 Kruskal，覆盖选边/拒绝成环边、达到 V-1 条终止/边耗尽终止。用例应包括连通三角形（边权 1、2、3，结果 3）、自环或重复边、等权边、负权边、单节点图、非连通图、非法端点与总权值较大的图。注意非连通图的错误输出是原实现的问题；“提示非连通”是修正后的预期，不是原程序已实现的功能。

### 问答题 2：矿区地下巷道无人运输机器人系统设计

**题目：** 设计矿区无人运输机器人系统，要求在无 GPS、粉尘、弱光环境下可靠定位，重载下坡道/湿滑路面稳定控制，识别矿车、人员、落石、设备等障碍物，支持固定线路与动态绕行，并对通信中断、制动异常和定位异常提供安全停车或降级机制。要求说明总体框架、至少一种核心功能的原理及上下游输入输出，并分析安全冗余、传感器可靠性、控制稳定性、运输效率和维护成本。

**参考答案：**

**总体架构：** 采用“感知采集 → 融合定位 → 地图与规划 → 运动控制 → 驱动执行”的分层闭环，并用独立安全监控模块贯穿各层。输入包括激光雷达、相机、IMU、轮速编码器及可选 UWB 的传感器数据；输出包括融合位姿、障碍物列表、规划路径、速度/转向/制动指令及故障告警。

**核心功能——多传感器融合定位：** 在 GPS 不可用时使用 LiDAR SLAM 提供几何位姿约束，IMU 高频预测位置/速度/姿态，编码器提供轮速里程计，关键路段可部署 UWB 锚点提供绝对测距辅助。用 EKF 预测与更新融合多源观测：统一时间戳与外参，IMU 做状态预测；轮速、雷达匹配位姿与 UWB 距离分别作为观测更新。对粉尘雷达离群点设置质量门限；当轮速与惯性/雷达运动不一致时怀疑打滑，降低轮速权重；长直重复巷道定位退化时用锚点或标志物抑制漂移。UWB 需另行部署并处理多径误差。

**感知、规划与控制：** 激光雷达与相机结合实现障碍物检测；固定任务用地图与 A* 等生成全局路径，动态障碍通过 DWA 等局部规划器调整速度或绕行；底盘采用速度闭环与坡道姿态反馈，结合轮速、IMU、电机电流和制动状态进行防滑控制，避免把单一 PID 当作全部复杂工况的保证。

**安全与成本：** 安全模块独立监测定位置信度、急停距离、制动健康、心跳及通信超时，触发限速、制动或硬件急停；关键状态应按安全等级设计冗余与失效保护。运输调度减少空驶，设备模块化、故障日志和预测性维护降低运维成本。粉尘、重复结构、湿滑及 UWB 多径均需现场标定和验证，不能仅凭框架断言已达成安全指标。

## 三、编程题（2 道，C++11，ACM 模式）

### 编程题 1：判断有向图是否存在环

#### 题目

给定有向图，节点编号为 0 到 n-1，共有 m 条有向边。若存在有向环则输出 YES，否则输出 NO。

#### 输入描述

第一行 n m；接下来 m 行，每行两个整数 u v，表示有向边 u→v。

#### 输出描述

输出 YES 或 NO。

#### 样例输入

~~~text
3 3
0 1
1 2
2 0
~~~

#### 样例输出

~~~text
YES
~~~

#### 思路

采用 Kahn 拓扑排序。统计入度，将所有入度为 0 的节点入队，依次删除这些节点及其出边；若最终处理节点数小于 n，说明图中存在环。时间 O(n+m)，空间 O(n+m)，无需递归深度风险。题目仅给单组输入，代码按单组处理。

#### C++11（ACM 模式）

~~~cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;
    vector<vector<int>> g(n);
    vector<int> indeg(n, 0);

    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        ++indeg[v];
    }

    queue<int> q;
    for (int i = 0; i < n; ++i)
        if (indeg[i] == 0) q.push(i);

    int cnt = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ++cnt;
        for (int v : g[u])
            if (--indeg[v] == 0) q.push(v);
    }
    cout << (cnt == n ? "NO" : "YES") << '\n';
    return 0;
}
~~~

### 编程题 2：完全二叉树数组表示的逐层输出

#### 题目

给定一棵二叉树的数组表示，-1 表示空节点；节点 i 的左孩子为 2i+1，右孩子为 2i+2。要求按层从左到右输出非空节点。

#### 输入描述

第一行 n；第二行 n 个整数。

#### 输出描述

第一行输出树的层数 h；接下来 h 行，每行输出该层从左到右的非空节点值。

#### 样例输入

~~~text
7
1 2 3 4 -1 6 7
~~~

#### 样例输出

~~~text
3
1
2 3
4 6 7
~~~

#### 思路

使用队列存储数组下标，从根节点 0 开始 BFS。每次固定队列长度处理一层，仅把数组范围内且不为 -1 的子节点入队；依次保存每层数据，最后先输出层数，再输出每层。只遍历从非空根实际可达的节点，不将 -1 当作真实节点。时间 O(n)，空间 O(n)。

#### C++11（ACM 模式）

~~~cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    if (n == 0 || a[0] == -1) {
        cout << 0 << '\n';
        return 0;
    }

    queue<int> q;
    vector<vector<int>> ans;
    q.push(0);

    while (!q.empty()) {
        int sz = (int)q.size();
        vector<int> level;
        while (sz--) {
            int i = q.front();
            q.pop();
            level.push_back(a[i]);
            long long l = 2LL * i + 1, r = l + 1;
            if (l < n && a[l] != -1) q.push((int)l);
            if (r < n && a[r] != -1) q.push((int)r);
        }
        ans.push_back(level);
    }

    cout << ans.size() << '\n';
    for (const auto& level : ans) {
        for (size_t i = 0; i < level.size(); ++i) {
            if (i) cout << ' ';
            cout << level[i];
        }
        cout << '\n';
    }
    return 0;
}
~~~
