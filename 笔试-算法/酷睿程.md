## 一、GPU 性能分析题

### GPU 利用率偏低：Profiler 分析与优化

**题目背景：**

GPU 训练/推理过程中 GPU 利用率偏低，需要结合 profiler 分析瓶颈，并说明 CUDA Stream、Event 等机制的作用与优化方法。

**答案与解析：**

GPU 利用率低不一定意味着 GPU 算力不足。常见原因包括：

1. kernel 很短且启动频繁，CPU 端 kernel launch 开销占比较高；
2. CPU 与 GPU 之间存在频繁同步，使 GPU 等待；
3. Host→Device 数据传输与 GPU 计算没有重叠；
4. 单个 kernel 工作量太小，难以充分占用 GPU。

可采用的优化措施包括：

- 使用多个 CUDA Stream，使数据传输与计算异步重叠；
- 使用 CUDA Event 在不同 Stream 之间建立依赖关系，避免不必要的全局同步；
- 使用 pinned memory 提升异步 H2D/D2H 传输效率；
- 对大量短 kernel 考虑 kernel fusion；
- 执行图稳定时可考虑 CUDA Graph，减少 CPU 端重复 kernel launch 开销。

### 第13题 大模型训练损失剧烈震荡

**题目：**

在训练大规模深度学习模型时，损失值剧烈震荡且不收敛，已排除数据问题。以下哪些超参数调整策略可以有效改善训练稳定性？

- A. 适当增大批大小并同步调整学习率
- B. 降低学习率并采用余弦退火调度
- C. 减少模型结构中的 Transformer 层数
- D. 延长学习率预热阶段

**答案：** A、B、D

**解析：**

降低学习率、延长 warmup 都可以直接降低训练初期或训练过程中的参数更新幅度；适当增大 batch size 可降低梯度估计噪声，并需要配合学习率调整。减少 Transformer 层数属于改变模型结构，并不是处理该训练震荡问题的常规超参数稳定化手段。

### 第14题 Softmax 数值稳定性

**题目：**

实现 Softmax 时，以下代码在输入数值较大时会导致溢出：

```python
def softmax(x):
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x)
```

为了同时保证数值稳定性和输出结果的正确性，最合适的修改方法是？

- A. 将 `np.exp(x)` 替换为 `np.tanh(x)`
- B. 将指数运算改为 `exp(x) / np.max(x)`
- C. 先将输入 x 归一化为均值为 0、方差为 1 的分布
- D. 将指数运算改为 `exp(x - np.max(x))`

**答案：** D

**解析：**

Softmax 对所有输入同时减去同一常数具有平移不变性。减去最大值后最大的指数项变为 `exp(0)=1`，可以有效避免指数上溢，同时不改变最终概率。

### 第15题 提升训练效率的超参数策略

**题目：**

在深度学习模型训练过程中，为提升训练效率，以下哪些超参数调整策略是合理有效的？

- A. 整个训练过程中固定学习率不变，以避免梯度波动
- B. 采用余弦退火等学习率调度策略，在训练后期逐步降低学习率
- C. 训练初期使用较小的学习率进行预热，逐渐增大至目标学习率

### 第17题 优化算法选择

**题目：**

训练深度神经网络时，遇到 loss 不下降或收敛缓慢，怀疑优化器配置不当。以下关于优化算法使用的说法，正确的有哪些？

- A. 相比 SGD，Adam 在训练初期收敛更快，但最终收敛精度可能稍逊于 SGD 的动量版本
- B. 对于非平稳目标（如 RNN），RMSprop 通常优于 SGD，因为它能够自动调整学习率
- C. Momentum 方法可以减轻梯度震荡，但必须配合学习率衰减才能收敛
- D. 当训练数据规模较大时，SGD 每次迭代只使用一个样本，导致计算效率远低于使用 mini-batch 的 Adam

**答案：** A、B

**解析：**

A 描述了常见经验现象；RMSprop 通过对梯度平方的移动平均进行自适应缩放，适合非平稳优化场景。Momentum 并非“必须”配合学习率衰减才能收敛；SGD 也完全可以使用 mini-batch，因此 D 将 SGD 错误等同于单样本更新。

### 第18题 AdamW

**题目：**

在 PyTorch 框架中训练深度学习模型时，关于 AdamW 优化器的使用，以下哪些说法是正确的？

- A. AdamW 在更新参数时，无需指定学习率，会自动优化
- B. AdamW 的权重衰减与学习率解耦，通常比标准 Adam 的 L2 正则化效果更稳定
- C. 通过 `torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)` 创建优化器，权重衰减会由优化器自动处理
- D. 使用 AdamW 优化器后，仍需要手动在损失函数中加入 L2 正则化项来等效实现权重衰减

**答案：** B、C

**解析：**

AdamW 的关键点是 decoupled weight decay。指定 `weight_decay` 后优化器会直接处理权重衰减，不需要为了实现同一效果再手动向 loss 添加 L2 项；学习率仍然是重要超参数。

### 第19题 GPU 利用率 40%、CPU 接近 100%

**题目：**

在 GPU 上训练深度学习模型，profiler 显示 GPU 利用率约 40%，而 CPU 占用率接近 100%。数据加载已优化且非瓶颈，以下哪个优化手段最有效？

- A. 将模型精度从 FP32 改为 FP16，减少 GPU 计算量
- B. 使用 CUDA Graph 捕获模型执行图，减少 CPU 端 kernel 启动开销
- C. 将优化器从 SGD 改为 Adam
- D. 增加 GPU 工作时钟频率

**答案：** B

**解析：**

题目已经指出 CPU 满载而 GPU 利用率低，并排除了数据加载瓶颈，说明更可能存在 CPU 端 launch/调度开销。CUDA Graph 能降低重复 kernel 启动的 CPU 开销。FP16 主要减少 GPU 计算负担，在 CPU 已成为瓶颈时甚至可能进一步缩短 GPU 工作时间。

### 第20题 回归任务损失函数

**题目：**

在深度学习回归任务中，训练数据存在少量噪声离群点，模型需要兼顾鲁棒性和收敛稳定性。以下关于损失函数选择的说法，正确的有哪些？

- A. Huber Loss 在误差较小时使用平方误差，误差较大时使用线性误差，有利于训练初期收敛和后期稳定
- B. 交叉熵损失函数适用于回归任务，且天然对离群点具有鲁棒性
- C. Huber Loss 对离群点不敏感，因为其误差较大时采用线性惩罚，减少了异常样本的梯度影响
- D. 均方误差（MSE）对离群点敏感，因为误差平方会放大异常样本的贡献，可能导致模型过度拟合

**答案：** A、C、D

**解析：**

Huber Loss 在小误差区域保持二次形式，在大误差区域转为线性增长，因此比 MSE 更能抑制离群点影响。普通交叉熵主要用于分类问题，不是这里的标准回归损失。

### 第21题 端侧部署优化

**题目：**

在将训练好的深度学习模型转换为端侧部署格式时，为了在保持可接受精度的情况下提升推理性能，以下哪些优化措施是合理的？

- A. 对不重要的连接进行剪枝，并在剪枝后进行微调以恢复精度
- B. 将卷积层与批归一化层融合，减少计算图节点数和数据搬运量
- C. 使用混合精度训练得到的模型直接转换，无需任何后处理即可获得最佳性能
- D. 对模型权重进行 INT8 量化，并使用代表性数据集进行校准，以最小化量化误差

**答案：** A、B、D

**解析：**

剪枝 + 微调、Conv-BN 融合以及带代表性数据校准的 INT8 量化都是常见端侧优化方法。混合精度训练并不能保证直接转换后无需校准、图优化或硬件适配就得到最佳部署性能。

## 三、Python 编程题

### 编程题：使用梯度下降思想求平方根

#### 已确认题面

给定正数 `y`，补全：

```python
def sqrt_by_gradient_descent(y):
    assert y > 0
```

使用迭代优化思想求 `sqrt(y)`。

> 原平台未配置可直接判分的测试用例，主要考察代码思路。实际调试中使用 `y=1000` 发现部分固定学习率/简单缩放学习率方案会产生 `nan`。

#### 调试复盘：为什么 y=1000 会出现 nan

若使用目标函数

```text
f(x) = (x^2 - y)^2
```

其梯度与

```text
2x(x^2-y)
```

成正比。若初始值直接取 `x=y=1000`，第一步梯度量级接近 `2×10^9`。

即使把学习率改成：

```python
lr = 0.1 / (y + 1)
```

当 `y=1000` 时学习率约为 `1e-4`，第一次更新仍可能把 `x` 从 1000 推到约 `-2e5` 的量级，随后梯度继续爆炸，浮点数溢出后出现 `inf/nan`。

因此问题不是简单“把固定学习率再调小一点”，而是梯度尺度随 `x` 和 `y` 急剧变化。

#### 稳定实现

可以对更新尺度进行归一化：

```python
def sqrt_by_gradient_descent(y):
    assert y > 0

    x = y if y >= 1 else 1.0
    lr = 0.1

    for _ in range(100000):
        grad = (x * x - y) / x
        new_x = x - lr * grad

        if abs(new_x - x) < 1e-10:
            return new_x

        x = new_x

    return x


def main():
    print(sqrt_by_gradient_descent(1000))


if __name__ == "__main__":
    main()
```

`y=1000` 时结果应接近：

```text
31.6227766017
```

#### 更快的自适应更新

若取：

```python
lr = 1.0 / (2.0 * x)
grad = x * x - y
x = x - lr * grad
```

则有：

```text
x_new = 1/2 * (x + y/x)
```

这实际上等价于求平方根的 Newton/Babylonian 迭代，数值稳定且收敛速度很快。若题目严格要求“gradient descent”，答题时应说明该自适应步长已经使更新形式等价于 Newton 迭代，避免概念混淆。
