# 一、深度学习与机器学习基础

## 14. What do you understand by L1 and L2 regularization?

### L1 正则化

L1 正则化是在损失函数中加入模型参数绝对值之和：

$$L=L_0+\lambda\sum |w|$$

作用：

- 限制模型参数大小，降低过拟合风险；
- 可以使部分参数变为 0，实现特征选择；
- 提高模型稀疏性。

### L2 正则化

L2 正则化加入参数平方和：

$$L=L_0+\lambda\sum w^2$$

作用：

- 限制权重过大；
- 使模型参数更加平滑；
- 减少过拟合，提高泛化能力。

区别：

| 方法 |特点|
|-|-|
|L1|产生稀疏模型，可用于特征选择|
|L2|参数整体变小，使模型更加稳定|

## 16. What are the benefits of pruning?

模型剪枝（Pruning）通过删除神经网络中不重要的参数或结构，降低模型复杂度。

优点：

- 减少模型参数量；
- 降低计算量和存储需求；
- 提升推理速度；
- 方便模型部署到嵌入式设备；
- 在一定程度上保持模型精度。

常见方式：

- 非结构化剪枝：删除单个权重；
- 结构化剪枝：删除通道、卷积核等结构。

## 17. What is the role of cross-validation?

交叉验证（Cross Validation）用于评估模型泛化能力，并辅助模型选择和参数调整。

以 K-fold 为例：

1. 将数据划分为 K 份；
2. 每次选择其中一份作为验证集，其余作为训练集；
3. 重复 K 次；
4. 计算平均性能。

作用：

- 减少单次数据划分带来的偶然性；
- 更可靠地评估模型性能；
- 帮助选择模型和超参数。

## 18. Can logistic regression be used for classes more than 2?

可以。

逻辑回归不仅可以用于二分类，也可以扩展到多分类：

### One-vs-Rest (OvR)

训练多个二分类模型，每个模型负责判断一个类别。

### Softmax Regression

将 sigmoid 扩展为 softmax，输出多个类别概率：

$$P(y=i)=\frac{e^{z_i}}{\sum e^{z_j}}$$

选择概率最大的类别作为预测结果。

## 19. If we have a high bias error what does it mean? How to treat it?

高偏差（High Bias）表示模型过于简单，无法学习数据中的有效规律，通常表现为欠拟合。

表现：

- 训练误差和测试误差都较高；
- 模型学习能力不足。

解决方法：

- 增加模型复杂度；
- 增加特征数量；
- 减少正则化强度；
- 增加训练时间；
- 使用更复杂模型结构。

## 21. What is the exploding gradient problem while using back propagation technique?

梯度爆炸指反向传播过程中，梯度不断增大，导致参数更新过大，使训练不稳定甚至无法收敛。

原因：

- 网络层数过深；
- 权重初始化过大；
- 梯度连续累积放大。

解决方法：

- Gradient Clipping（梯度裁剪）；
- 合理初始化权重；
- 使用 Batch Normalization；
- 使用 ReLU 等激活函数；
- 使用残差结构（ResNet）。

## 22. What is depthwise separable convolution and its advantages?

Depthwise Separable Convolution 将普通卷积分解为：

1. Depthwise Convolution：每个输入通道独立卷积；
2. Pointwise Convolution：使用 1×1 卷积融合通道信息。

优势：

- 大幅降低参数量；
- 减少计算量；
- 加快推理速度；
- 适合移动端和嵌入式部署。

典型应用：

- MobileNet。

## 23. 池化层的作用是什么？介绍几种池化方式

池化层主要作用：

- 降低特征图尺寸；
- 减少计算量；
- 提高模型平移不变性；
- 提取更加鲁棒的特征。

常见池化方式：

### Max Pooling

选择窗口中的最大值，突出明显特征。

### Average Pooling

计算窗口平均值，使特征更加平滑。

### Global Average Pooling (GAP)

对整个特征图求平均，将二维特征转换为一个值，常用于分类网络。

# 二、计算机基础

## 堆和栈哪个访问效率高？为什么？

通常栈访问效率更高。

原因：

- 栈由系统自动管理，内存连续；
- 分配和释放速度快；
- CPU 缓存友好。

堆：

- 动态分配；
- 需要查找空闲空间；
- 可能产生内存碎片。

但是堆可以动态管理生命周期，更灵活。

# 三、数据不平衡问题

## 深度学习中使用数量不平衡样本训练会出现什么结果？如何解决？

类别不平衡会导致模型偏向多数类别。

例如：

95% 为 A 类，5% 为 B 类时，模型可能大量预测为 A 类，导致 B 类召回率很低。

影响：

- Accuracy 虚高；
- 少数类别识别能力差；
- 泛化能力下降。

解决方法：

## 数据层面

- Oversampling：增加少数类样本；
- Undersampling：减少多数类样本；
- 数据增强。

## 损失函数层面

- Class Weight；
- Weighted Cross Entropy；
- Focal Loss。

## 训练策略

- Balanced Batch Sampling；
- 分层采样。

评估指标应使用：

- Precision；
- Recall；
- F1-score；
- 混淆矩阵；
- PR-AUC。
