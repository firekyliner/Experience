# Experience

个人求职笔试与面试复盘仓库。

本仓库用于持续整理校招/求职过程中真实遇到的笔试题、编程题、技术面问题、项目追问与 HR 问题，并补充参考答案、解题思路和复盘建议。内容以“真实记录 + 后续整理”为原则，不凭空补题。

- **笔试-嵌入式**：以嵌入式、C/C++、底层系统和相关岗位为主要方向。
- **笔试-算法**：以算法、AI、机器学习、视觉、ISP 与深度学习为主要方向。
- **面试-嵌入式 / 面试-算法**：按照应聘岗位方向分别存放；空目录不由 Git 跟踪，首次添加记录时建立。
- **混合题型**：按实际应聘岗位或主要考察方向归档，不因包含算法题或 C++ 题而自动改变类别。
- **岗位名称**：现有索引暂统一为「感知算法工程师」「嵌入式软件」「图像算法工程师」；历史记录中的原始岗位名称保留在正文，不视为已核实具体招聘岗位。
- **题型及时间**：按材料可确认的数量写成「N道选择题 + N道编程题（2h）」；时长未知明确写「时长未记录」。
- **agent.md**：统一规定分类、命名、记录格式和索引维护要求。

## 整理原则

1. 优先保留真实题面、真实追问与真实现场信息。
2. 题目不完整时明确标注，不把推测内容伪装成原题。
3. 笔试题提供答案、解析和可复用思路。
4. 先按岗位方向归类到四个目录之一，再更新索引；文档格式与命名遵循 [agent.md](agent.md)。
