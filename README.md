# Experience

## 整理原则

1. 优先保留真实题面、真实追问与真实现场信息。
2. 题目不完整时明确标注，不把推测内容伪装成原题。
3. 笔试题提供答案、解析和可复用思路。
4. 文档格式与命名遵循 [agent.md](agent.md)。
