## 整理原则

1. 优先保留真实题面、真实追问与真实现场信息。
2. 题目不完整时明确标注，不把推测内容伪装成原题。
3. 笔试题提供答案、解析和可复用的 ACM 代码思路。
4. 面试题区分“实际问题”和“建议回答”，个人日期、城市偏好、爱好、求职进度等无法从记录确认的信息必须留待本人填写。
5. 文档格式与命名遵循 [agent.md](agent.md)。
